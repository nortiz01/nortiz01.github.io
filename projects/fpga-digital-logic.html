FPGA / DIGITAL LOGIC

FPGA Digital Logic

A collection of FPGA-based digital logic designs implemented, compiled, simulated, and verified using Intel/Altera Quartus Prime and the Intel MAX 10 platform.

FPGA Quartus Prime MAX 10 Digital Logic Functional Simulation
GitHub Repository View Source Files

OVERVIEW

1-Bit Full Adder

The first completed design in this collection is a 1-bit full adder. The circuit performs binary addition on three one-bit inputs and produces a SUM output and a CARRY output.

The original project was developed as part of digital-logic coursework using Quartus Prime Lite 18.1. For this portfolio, I recovered the original project files, reorganized the project, recompiled it in Quartus Prime Lite 25.1, reran the functional simulation, and documented the results.

DESIGN

Circuit Implementation

The full adder was implemented using logic gates in the Quartus Block Diagram/Schematic Editor. Inputs A and B represent the two binary values being added, while C represents the carry-in from a previous stage.

VERIFICATION

Functional Simulation

Functional verification was performed using the Quartus Simulation Waveform Editor. The test waveform exercises all eight possible combinations of A, B, and C.

The simulated SUM and CARRY signals matched the expected truth table for every test case.
